# 基于非遗文化元素的动态光色疗愈体验软件V1.0

著作权人：陕西理工大学
经办人 / 负责人：李果

## 运行环境

- Node.js 22 或更高版本，无需安装第三方依赖
- 浏览器需支持 Canvas 2D、Web Audio API 与 ES Module
- 推荐分辨率 1920×1080，Chrome 或 Edge 最新稳定版

## 启动

```powershell
node server.js
```

默认地址：`http://127.0.0.1:4102`

可通过环境变量修改端口与数据目录：

```powershell
$env:PORT=4102
$env:DATA_DIR="E:\p02-data"
node server.js
```

## 初始账号

| 角色 | 用户名 | 初始密码 |
|---|---|---|
| 终端用户 | user01 | User@2026 |
| 非遗内容管理员 | expert01 | Expert@2026 |
| 系统管理员 | admin01 | Admin@2026 |

首次登录后可在“个人资料”修改密码。上表为本地演示用的初始化账号，不属于生产凭据；部署时应立即修改密码，并妥善保管`data`目录。

## 数据与文件

- `data/db.json`：业务数据，首次启动自动生成初始业务样本
- `data/uploads/`：非遗素材文件
- `data/secret.key`：登录令牌签名密钥，首次启动自动生成，不对外输出

备份时停止服务后复制整个`data`目录；恢复时用备份目录替换`data`后重新启动。

## 主要功能

- 终端用户：情绪测评、语音特征采样、主题推荐、自定义配方、动态光色体验、环境音、灯光指令导出、记录与趋势、报告导出、文化科普卡、反馈与投诉
- 内容管理员：素材上传与编辑、主题创建与启停、聚合统计
- 系统管理员：素材审核、账号管理、操作日志、系统设置、投诉处理

## 说明

本软件用于日常放松与文化体验，不提供医学诊断或治疗。视频或图片材料中的界面均来自本工程实际运行。
